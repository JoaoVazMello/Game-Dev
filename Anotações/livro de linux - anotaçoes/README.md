# 📘 Nome : The Linux Command Line

Autor: William Shotts  
Ano: 2019  
Área: Sistemas Operacionais / Linux

---

## 📖 Sobre o Livro

Este livro apresenta os fundamentos do uso do sistema operacional Linux através da linha de comando, abordando desde conceitos básicos até tópicos mais avançados como manipulação de arquivos, permissões, processos e automação com scripts.

O foco está em ensinar como utilizar o terminal de forma eficiente, explorando o poder das ferramentas nativas do Linux.

---

## 🎯 Objetivo do Estudo

Motivo pelo qual escolhi estudar este livro:

- Aprender a utilizar Linux de forma profissional
- Ganhar domínio sobre linha de comando
- Preparar base para trabalhar com servidores
- Melhorar produtividade no desenvolvimento

---

## 🧠 Principais Conceitos Estudados

- Navegação e manipulação de arquivos
- Comandos essenciais do Linux
- Permissões e controle de acesso
- Gerenciamento de processos
- Redirecionamento e pipes
- Shell scripting (bash)
- Variáveis de ambiente

---

## 🔬 Aplicações Práticas

Como apliquei ou pretendo aplicar o conteúdo:

- Uso do terminal como principal ferramenta de desenvolvimento
- Automação de tarefas com scripts bash
- Configuração de servidores Linux
- Gerenciamento de arquivos e processos em ambiente real
- Integração com projetos de backend e infraestrutura
