
## 💾 Servidores

Este diretório tem como objetivo documentar minha jornada no estudo de servidores, redes e infraestrutura, abordando conceitos fundamentais e avançados como:

- Configuração de servidores
- Sistemas operacionais (Linux/Windows Server)
- Redes de computadores
- Virtualização e containers
- Segurança
- Automação

Além disso, desenvolvo projetos práticos como:

- Servidores locais (home server)
- Servidores para jogos (ex: Minecraft)
- Sistemas de armazenamento e backup
- Ferramentas de acesso remoto
- Simulações de ambientes reais

Toda a documentação segue o mesmo padrão utilizado no restante do repositório, com anotações em Markdown organizadas para facilitar o aprendizado contínuo.

Assim como nos outros diretórios, o foco não é apenas registrar conteúdo, mas consolidar conhecimento através da prática e da escrita.

---

## 🚀 Objetivos

Meu foco é desenvolver domínio em:

- Administração de servidores
- Infraestrutura de redes
